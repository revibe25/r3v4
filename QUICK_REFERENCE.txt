💾 TOKEN STORAGE

After login, check DevTools (F12):
  Application → Local Storage → http://localhost:5173

Keys to verify:
  • r3_token         → Your JWT (format: xxx.yyy.zzz)
  • r3_token_expiry  → Expiration timestamp
  • r3_refresh_token → Refresh token (if applicable)

🔐 AUTH SERVICE API

Login:
  const result = await AuthService.login('ernesto', 'test123456');
  // Returns: { token, user, expiresIn, refreshToken }

Get current token (auto-refresh if expired):
  const token = await AuthService.getToken();

Check if authenticated:
  const isAuth = AuthService.isAuthenticated();

Get user info:
  const user = AuthService.getUser();
  // { id, username, email? }

Logout:
  AuthService.logout();

Test endpoint:
  const result = await AuthService.testEndpoint();
  // { status: 'OK'|'FAIL', message: string }

🎣 REACT HOOK API

useAuth() — Get auth state anywhere:
  const {
    user,              // { id, username, email? }
    token,             // JWT string
    isAuthenticated,   // boolean
    isLoading,         // boolean
    error,             // Error or null
    login,             // async function
    logout,            // function
    clearError         // function
  } = useAuth();

Usage:
  const { login, error, isLoading } = useAuth();
  
  const handleLogin = async () => {
    try {
      await login('ernesto', 'test123456');
      // Logged in, will redirect via ProtectedRoute
    } catch (err) {
      console.error('Login failed:', err);
    }
  };

🛣️ PROTECTED ROUTE USAGE

Wrap routes that require authentication:

  <Route
    path="/instrument"
    element={
      <ProtectedRoute>
        <InstrumentPage />
      </ProtectedRoute>
    }
  />

Behavior:
  • Authenticated user → Renders component
  • Not authenticated → Redirects to /auth
  • Loading state → Shows "Loading..."

⚠️ COMMON ISSUES

"Cannot reach /auth endpoint"
  → Dev server not running: pnpm dev
  → Check REACT_APP_API_URL in .env
  → Verify /auth endpoint exists on server

"Login successful but no redirect"
  → Check localStorage for r3_token
  → Verify React Router redirect path
  → Check browser console for errors

"Protected route blocks everyone"
  → Ensure <AuthProvider> wraps your routes
  → Check isAuthenticated state in AuthDebugger
  → Verify token is stored in localStorage

"Token refresh fails"
  → Backend needs /auth/refresh endpoint
  → Check refreshToken is stored
  → Verify API accepts refresh token format
