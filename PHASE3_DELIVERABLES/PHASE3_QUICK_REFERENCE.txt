Phase 3 applies **7 critical corrective patches** to the AudioGraph measurement engine, fixing defects in:

## The 7 Patches

### Patch 1: Stereo Energy Weighting
**Issue:** Stereo loudness measured 3.01 dB lower than mono (incorrect)  
**Root Cause:** Division by `2 * N` instead of `N`  
**Fix:** Change divisor from `(2 * this.kLeftBuffer.length)` to `this.kLeftBuffer.length`  
**Standard:** ITU-R BS.1770-5 §3.2 specifies Σ(L² + R²) / N  
**Lines:** ~444–450

### Patch 2: LUFS Block Timing
**Issue:** No documentation on animation-frame timing approach  
**Root Cause:** Design decision was not explained in code  
**Fix:** Add documentation comment explaining approach (no code change)  
**Standard:** Phase 2 Choice B (animation-frame, not streaming)  
**Lines:** ~98–146

### Patch 3: Correlation Normalization
**Issue:** Correlation formula was peak-normalized (wrong for phase analysis)  
**Root Cause:** Used peak values instead of energy values  
**Fix:** Implement Pearson energy-normalized correlation: `Σ(L×R) / √(ΣL² × ΣR²)`  
**Standard:** Web Audio API correlation semantics  
**Lines:** ~189–206

### Patch 4: Stereo Width Metric
**Issue:** Stereo width formula was undefined  
**Root Cause:** Conditional logic didn't clearly express the metric  
**Fix:** Replace with simple formula: `stereoWidth = 1 - |correlation|`  
**Standard:** Phase 2 Choice C  
**Lines:** ~208–213

### Patch 5: True-Peak Metering
**Issue:** False claim of "4× interpolation" via ×1.05 heuristic  
**Root Cause:** Misunderstood cubic Lagrange interpolation  
**Fix:** Remove multiplier, add documentation, implement decay hold  
**Standard:** AnalyserNode 2048-sample window = 46ms @ 44.1kHz  
**Lines:** ~220–229

### Patch 6: Gain Reduction API
**Issue:** Fabricated gain reduction from peak amplitude  
**Root Cause:** No integration with Web Audio DynamicsCompressor  
**Fix:** Use `limiter.reduction` API (hardware-backed measurement)  
**Standard:** Web Audio API standard  
**Lines:** ~231–237

### Patch 7: Dead Code Cleanup
**Issue:** Unused variable `correlationHold` declared  
**Root Cause:** Legacy code from previous design  
**Fix:** Delete the declaration  
**Standard:** Code quality  
**Lines:** ~75–100 (declaration)
